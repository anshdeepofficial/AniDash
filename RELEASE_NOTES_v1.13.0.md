# AniDash v1.13.0 — New AD Brand Identity

## What’s new

- Replaced the previous AniDash logo with the new official **AD** mark throughout the app.
- Added coordinated light and dark logo variants:
  - Light mode: white background with a black AD mark.
  - Dark mode: black background with a white AD mark.
- Updated Dynamic, White, and Black launcher-icon modes while preserving the existing user preference.
- Rebuilt Android adaptive, round, legacy, monochrome, Play Store, and notification icons from the same AD master.
- Updated the About screen, loading UI, privacy cover, theme preview, and security UI to use the shared theme-aware logo.
- Updated Windows, Linux, web, iOS, and macOS application icons.
- Updated the GitHub README branding and removed the obsolete logo files.

## Upgrade note

Some Android launchers cache application icons. If the old icon briefly remains after updating, restart the launcher or device once; AniDash’s saved Dynamic/White/Black logo selection will remain intact.
