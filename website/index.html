Frequently asked

Quick answers.

What exactly is AniDash?

AniDash is an anime companion that brings discovery, playback, downloads, Continue Watching, library management and supported manga browsing into one interface.

Do I need an account?

No. Local history, Continue Watching and library features can work without connecting an account. AniList sign-in is optional for account-based list syncing.

Does AniDash host anime or manga files?

No. AniDash is a client application. It displays metadata and connects to user-selected or supported content sources; it does not host the media shown in the app.

Can I watch offline?

Supported episodes can be downloaded to your device for offline playback, subject to the selected source and available device storage.

What platforms are supported?

Android is available now. The iOS build is in production, and a desktop release is planned.

Where do updates come from?

The website checks the official GitHub releases for the latest Android APK. You can also follow releases directly on GitHub or use Obtainium.
