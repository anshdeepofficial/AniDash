Features

More than a player.

AniDash connects discovery, playback, progress, offline viewing and manga in one experience.

▶

Online playback

Open supported episodes in the built-in player and choose an available source.

SUB

SUB / DUB preference

Keep your selected language when that version is available.

↓

Offline downloads

Save supported episodes to device storage for later playback.

✓

Continue Watching

Resume from where you stopped across supported online and downloaded playback.

⌕

Discovery & search

Trending, popular, recently updated, upcoming and fast search.

▤

Library

Watching, Completed, Planning, Paused and Dropped lists locally or with AniList.

M

Manga

Browse and read supported manga through MangaDex.

F

Filler information

Supported episode lists can highlight filler content.

↗

Watch order

View available watch-order information before starting a series.

◐

Themes

Light, dark, AMOLED and dynamic-color options.

▦

UI customization

Card styles, banners and layout preferences let the interface adapt to you.

⇄

Multiple sources

Switch between supported installed sources when one is unavailable.
