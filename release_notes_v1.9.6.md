# AniDash 1.9.6

Developer: Anshdeep Singh
GitHub: anshdeepofficial

## Fixes and improvements

- Restored the player Settings button in the bottom control bar.
- Fixed invalid intro/outro timestamps causing unexpected mid-episode auto-advance.
- Strengthened filler episode highlighting using the user's selected theme color.
- Added a 30-second/64 MB adaptive forward cache, safer underrun recovery,
  background demuxing, and HTTP reconnection for sustained smooth playback.
- Fixed the external launcher logo for Dynamic, White, and Black modes.
- Dynamic launcher logo now follows Android light and dark mode correctly.
- Hardware volume keys now use the player overlay without the Android volume popup.
- Swapped gesture sides: left controls volume and right controls brightness.
- Added two-stage VLC-style volume: stop at 100%, then boost on a new swipe.
