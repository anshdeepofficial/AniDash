# AniDash v1.17.1 — Stability & Comfort Update ✨

This update focuses on making everyday watching clearer, safer, and more reliable without replacing the streaming engine that already works well.

## What’s improved

- 🎬 **Smoother player controls:** Double-tap seeking now moves the video instantly while still showing the combined 10s, 20s, 30s feedback.
- ⚡ **Speed control everywhere:** Press and hold anywhere on the video—not only the right side—to use temporary 2×/3×/4× playback.
- ⏭️ **Cleaner next episode flow:** After tapping the next-episode card, it disappears while the selected episode opens instead of changing to the following episode.
- 📺 **Continue Watching stays reliable:** Guest progress remains available after reopening the app, and unfinished shows with an unknown total episode count are no longer removed by mistake.
- ✅ **Mark as Watched works clearly:** Marking an episode complete immediately prepares the next episode and confirms what is up next.
- 🔊 **Better volume controls:** Hardware volume buttons work with AniDash’s own player feedback and the player volume range is a consistent 0–100.
- 🔒 **Compact player menu:** The three-dot menu uses a cleaner right-side panel with more useful controls in less space.
- 🔔 **Permission controls fixed:** Notification permission is requested only when you enable it, while modern Android app storage works without unnecessary broad storage access.
- 🧩 **Clearer extensions:** Compatible MangaYomi JSON sources install inside AniDash; unsupported AniYomi APK repositories now show a clear explanation instead of opening a separate-app installer.
- 🔎 **Settings search:** Quickly find the setting you need from the Settings screen.
- 🎨 **Icons restored:** Release builds now include the complete icon fonts, preventing missing icons, boxes, or unrelated characters.
- 🔗 **Official links updated:** GitHub profile, repository, issues, releases, and update links now use `anshdeepofficial1`.

## Playback safety

- The working online streaming source and buffering engine were not redesigned in this update.
- Playback, buffering, request-header, download-progress, notification, and Continue Watching regression tests passed before release.
